## About Me

I'm **Clarence Librando**, a **4th-year BSCS student at EARIST Manila (2023–Present)** specializing in **full-stack web, AI/RAG systems, cross-platform desktop, and native mobile development**.

I build end-to-end production systems — from low-latency microservices and vector retrieval pipelines to native mobile clients and multi-threaded desktop utilities. Currently focused on my thesis **CIVIL-LEX**, which pairs a **grounded RAG system over Philippine civil law** with a **fine-tuned LLM for RAG**. Seeking a **Software Engineering / IT internship**.

**Relevant coursework:** Data Structures and Algorithms, OOP, Operating Systems, DBMS, Computer Networks, Mobile Computing, Intelligent Systems.

- Thesis: **CIVIL-LEX** — (1) RAG over Civil Code RA 386 + Family Code EO 209, (2) fine-tuned `civilex-gemma-4-e4b` + `civil-code-phil` dataset
- Interests: Kotlin Multiplatform, Next.js + TypeScript, Supabase/PostgreSQL + pgvector, Docker, RAG evaluation (RAGAS)
- Workflow: Linux (Fedora/Ubuntu), Android Studio, VS Code, OpenCode, GitHub, Hugging Face
